AI Enabled NVR

Developed an AI‑enabled Network Video Recorder (NVR) that integrated advanced object detection and tracking into existing surveillance infrastructure. The solution supported multiple channels simultaneously, providing real‑time video analytics and streaming of structured metadata for enhanced monitoring and security.

AI NVR Object Detection Object Tracking Video Analytics YOLO QT UI C++ Backend XML Data Streaming Multi‑Channel Support

Project Description

We created a multi‑object detection and tracking engine that combined temporal, spatial, and object property analysis (face, pose, color, license plate). This engine was integrated into the existing NVR system, enabling each video feed to deliver analytics alongside standard recording.

Key Features Delivered:
  • Hybrid detection using temporal, spatial, and object properties
  • Face, pose, and clothing color recognition for individuals
  • License plate recognition (LPR) as an optional feature for vehicles
  • XML‑based analytic data streaming channel for structured metadata
  • Support for 16 channels at 25fps with real‑time analytics
  • QT‑based user interface for monitoring and control
  • Seamless integration with the original C++ NVR backend

In addition, the system provided attribute detection (Experimental Level Accuracy) such as age estimation, clothing color identification, and vehicle license plate recognition or vehicle type identification, enhancing situational awareness and enabling richer analytics for surveillance operators.

Tools & Technologies

The solution was implemented in C++, leveraging a modified YOLO network for deep learning‑based detection and deep-SORT tracking. QT was used to build the user interface, while XML channels were introduced for structured analytic data streaming. The architecture emphasized real‑time performance, scalability, and compatibility with existing NVR systems, ensuring smooth deployment without disrupting legacy workflows.
