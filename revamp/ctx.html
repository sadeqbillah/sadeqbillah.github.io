Cloth Color Transfer System

The Cloth Color Transfer project introduces an intelligent system that enables fashion outlets to digitally change the color of garments in pre‑shoot model images. By eliminating the need for multiple photoshoots for each color variant, the system reduces production costs by approximately 50% per model shoot, streamlining the workflow for e‑commerce and fashion photography.

Cloth Color Transfer Fashion Technology Image Segmentation CRF Enhancement Deep Learning Cost Optimization TensorFlow Flask Web Service Next.js Interface

Project Description

I contributed in a CIHP‑PGN‑based segmentation network to accurately identify body parts and clothing regions in model images. The segmentation output is refined using Conditional Random Field (CRF) enhancement, incorporating user feedback for improved precision.

A Next.js‑based user interface allows users to select specific clothing segments (e.g., upper garment, bottom garment) and change their colors interactively using a color picker. This approach enables fashion companies to photograph only one variant of each product and digitally generate all other color options, saving both time and model fees.

Key Features Delivered:
  • Near real‑time inference pipeline (23s → 2s)
  • Placeholder configuration for image resizing
  • Correct label preservation using PIL resize
  • Automatic class merging (e.g., outer + dress, pants + skirt)
  • Boundary optimization using CRF (with noted limitations)
  • Accuracy ~73% on test datasets
  • Manual adjustment support for complex textures or patterns

Tools & Technologies

Our system combines deep learning, web development, and interactive design. The segmentation and enhancement pipeline runs on TensorFlow, while Flask serves as the communication bridge between the model and the web interface. The Next.js front‑end provides a responsive, user‑friendly environment for color manipulation and feedback collection.
