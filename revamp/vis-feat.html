Panorama Quality Assessment

Developed an objective quality assessment method for stitched and warped images to evaluate geometric and photometric distortions. Unlike traditional approaches that relied solely on subjective evaluation, this solution introduced a Delaunay‑triangulation based framework for quantifiable, repeatable, and accurate image quality measurement.

Image Stitching Objective Quality Assessment Delaunay Triangulation Affine Transformation PSNR Geometric Distortion Computer Vision

Project Description

We proposed and implemented a novel assessment method that addressed the lack of objective evaluation tools in stitched image processing. The approach segmented reference and target images using Delaunay triangulation based on matched points, enabling precise measurement of geometric distortions. By calculating the average Euclidean distance between triangulated segments, the system provided a robust metric for alignment accuracy.

Key Features Delivered:
  • Delaunay‑triangulation based segmentation of reference and target images
  • Geometric distortion measurement using average Euclidean distance
  • Photometric distortion evaluation using PSNR averages and histograms
  • Affine transformation handling for stitched/warped image comparison
  • Objective framework enabling algorithm benchmarking beyond subjective evaluation

This method demonstrated improved reliability in comparing stitching algorithms, offering both computational efficiency and quantitative accuracy for geometric and photometric distortion analysis.

Objective quality assessment method for stitched images

Recently, stitching techniques are used for obtaining wide FOV, eg, panorama contents, from normal cameras. Despite many proposed algorithms, the no objective quality evaluation method is developed, so the comparison of algorithms are performed only in subjective way. The paper proposes a'Delaunay-triangulation based objective assessment method'for evaluating the geometric and photometric distortions of stitched or warped images. The reference and target images are segmented by Delaunay-triangulation based on matched points between two images, the average Euclidian distance is used for geometric distortion measure, and the average or histogram of PSNR for photometric measure. We shows preliminary results with several test images and stitching methods for demonstrate the benefits and application.

Tools & Technologies

The solution was implemented in C++ with CLI WinForms, leveraging OpenCV for image processing and transformation operations. The architecture combined Delaunay triangulation for geometric segmentation, affine transformation for alignment, and PSNR metrics for photometric distortion evaluation. This ensured a scalable and repeatable framework for assessing stitched images across diverse datasets.
