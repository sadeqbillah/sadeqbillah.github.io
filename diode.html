Micro Diode Inspection System

The Micro‑Level Diode Inspection System is an AI‑powered solution designed to detect defects in small automotive diodes. Initially developed without NG (defective) samples, the system leveraged anomaly detection to identify irregularities. Over time, it evolved into a hybrid pipeline combining defect localization with segmentation‑based classification, ensuring high accuracy and reliability for industrial inspection.

Micro‑Level Diode Inspection Automotive Electronics PatchCore Algorithm Defect Localization Segmentation‑Based Classification Computer Vision Industrial Automation OpenCV C#

Project Description

At the outset, the challenge was the absence of NG samples. We relied solely on customer‑provided OK samples and synthetic NG data. Leveraging the newly released PatchCore algorithm, we achieved strong results in defect localization. For the first two years, the system operated without classification, focusing exclusively on identifying defective regions. This approach significantly reduced manual inspection needs, which previously required multiple human inspectors to detect subtle defects.

As NG samples became available, we advanced the system by integrating segmentation‑based classification. This allowed us not only to localize defects but also to categorize them, improving diagnostic precision. The inspection pipeline was built around a motion table that moved diode pallets through the vision area, enabling systematic scanning. The combination of PatchCore localization and segmentation classification created a robust, scalable solution for industrial deployment.

Key Features:
  • PatchCore‑based defect localization
  • Synthetic NG sample testing for early validation
  • Segmentation‑based classification for defect categorization
  • Motion table for automated pallet scanning
  • High accuracy in micro‑defect detection
  • Reduced reliance on human inspectors

The project resulted in an inspection methodology for micro‑level diode defects. It became a critical system for automotive electronics quality assurance, reducing inspection manpower requirements and improving defect detection reliability.
