Map Based Surveillance System

Developed and commercialized the Sentec M‑Tracker bird’s‑eye surveillance system, enabling large‑area monitoring and intelligent object tracking beyond individual CCTV feeds. The system integrated AI‑driven analytics, IoT sensors, and edge computing to deliver real‑time detection, classification, and re‑identification. It achieved GS (Good Software) certification (ISO/IEC 25023, 25051, 25041), K‑Mark, and Excellent Product Certification, validating its innovation, quality, and reliability for procurement.

Project Description

We designed, researched, and developed the prototype and core functionalities of the M‑Tracker system, leading to ideation, submission, and grant of two patents: Map‑Based Intelligent Surveillance System [1019368370000] and Affine Transformation from CCTV Stream [1019752090000]. The system aggregated analytics from multiple cameras, ensuring that only one track was shown per object in the map view through re‑identification. Tracks older than 10 minutes were automatically removed, maintaining clarity and efficiency.

Key Features Delivered:
  • Multi‑channel object detection, classification, and tracking
  • Object re‑identification across multiple cameras with unique IDs
  • Projection of camera objects onto map view for spatial awareness
  • People and vehicle counts per location
  • Live and recorded video playback
  • Region‑based alarm mechanisms (intrusion detection)
  • Configurable rules and actions for alarms (email, SMS, on‑screen message, MMS, etc.)
  • IoT sensor integration (heat sensors, LP readers, face/fingerprint recognition)
  • Face recognition and license plate recognition for identity assignment

We leveraged the Smart NVR backend for individual channel analytics and multi‑channel aggregation. Unique IDs were assigned to detected objects, enriched with time and location metadata. When re‑identified by face detection or license plate readers, objects were assigned names or license plate numbers, enabling meaningful tracking and output data.

Tools & Technologies

The solution was built on an AI server using C/C++ for backend processing, integrated with RTSP for video streams, MQTT for lightweight messaging, and WCF for service communication. On the client side, C# WinForms with VG.net animated vector graphics and DirectDraw provided a responsive UI. SQL Server Enterprise managed structured data, while IoT sensors and edge computing devices ensured scalability and reduced server load. The architecture emphasized real‑time analytics, certification compliance, and maintainability, enabling successful commercialization.
