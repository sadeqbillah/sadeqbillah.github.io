VR/AR Try-On System

Developed a Javascript‑based AR/VR solution for mobile clients as part of a virtual try‑on service for a leading footwear provider. This project extended the earlier OpenGL‑based try‑on system into a web‑friendly version, enabling users to experience real‑time shoe fitting through their mobile browser without requiring native apps.

AR/VR Virtual Try‑On Javascript TensorFlow.js Three.js MindAR Web‑Based Rendering Mobile Clients Footwear Industry

Project Description

We implemented a web‑based AR/VR pipeline that identified and tracked user feet in live camera feeds using TensorFlow.js. A predefined 3D human foot surface model was dynamically adjusted to match the user’s foot size, and Three.js was used to calculate the render area and remap virtual shoes onto the detected surface. MindAR ensured that the virtual shoe moved naturally with the user’s foot movements, creating a realistic try‑on experience.

Key Features Delivered:
  • Real‑time foot detection via TensorFlow.js
  • Dynamic 3D foot surface modeling and adjustment
  • Virtual shoe rendering and remapping with Three.js
  • Motion tracking and alignment using MindAR
  • Web‑based AR/VR try‑on accessible via mobile browsers

This solution allowed the client to offer a scalable, browser‑based AR/VR experience, reducing dependency on native applications and expanding accessibility for end users.

Tools & Technologies

The solution was built entirely in JavaScript, leveraging TensorFlow.js for machine learning‑based detection, Three.js for 3D rendering and surface mapping, and MindAR for augmented reality tracking. The architecture emphasized lightweight performance, cross‑platform compatibility, and scalability, ensuring smooth operation on mobile browsers without requiring native installations.
