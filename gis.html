Glass Inspection Remodelling

The Display Glass Inspection System is the flagship product used across multiple Samsung Display, LG Display, and TCL factories worldwide. Originally built as a monolithic application, it suffered from runtime instability and maintenance challenges. The system was redesigned into a distributed architecture using MQTT messaging, dramatically improving reliability, scalability, and client satisfaction.

Display Glass Inspection Distributed System MQTT Messaging System Redesign Industrial Automation Fault Isolation Software Architecture Reliability Engineering Client Support Optimization

Project Description

We transformed the legacy monolithic inspection system into a modular, distributed architecture with clear cohesion and coupling between components. The previous implementation relied on a single, lengthy function that handled all operations, making debugging and maintenance extremely difficult. By decomposing the system into independent modules communicating via MQTT, we achieved real‑time fault isolation and improved traceability. The system can be deployed in a single or multiple machines with flexibility to assign different components to the same or different PCs.

The new design enables each subsystem to operate autonomously while exchanging messages through a lightweight broker. This allows precise error reporting and faster recovery from failures. As a result, service‑level complaints dropped significantly, and client support became more efficient and transparent.

Key Features:
  • Modular distributed architecture replacing monolithic design
  • MQTT‑based inter‑component communication
  • Real‑time error detection and reporting
  • Improved maintainability and scalability
  • Mask‑based and mask‑less warping modes
  • 90% reduction in client support requests
  • 70% reduction in on‑site service visits

The redesigned system became the core operational model for global deployments at Samsung Display, LG Display, and TCL factories. It earned internal recognition for engineering excellence and was documented in a technical white paper outlining the transition from monolithic to distributed architecture.
