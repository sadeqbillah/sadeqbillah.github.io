Cloth Segmentation API

Developed and optimized a Clothing Segmentation API based on the CIHP‑PGN network, enabling near real‑time inference for fashion image processing. The system reduced inference time from 23 seconds to just 2 seconds, while improving segmentation accuracy and handling class merging, resizing, and boundary optimization challenges.

Clothing Segmentation CIHP‑PGN CRF Optimization PIL Resize OpenCV Python Fashion AI Image Processing API Development

Project Description

We prepared a speed‑optimized inference pipeline for the CIHP‑PGN network, reducing processing time significantly. A placeholder mechanism was introduced, allowing admins to configure image sizes before inference. We solved a critical issue with OpenCV’s NEAREST resize method, which incorrectly altered label sets, by switching to the PIL library for resizing, ensuring label consistency.

Key Features Delivered:
  • Near real‑time inference pipeline (23s → 2s)
  • Placeholder configuration for image resizing
  • Correct label preservation using PIL resize
  • Automatic class merging (e.g., outer + dress, pants + skirt)
  • Boundary optimization using CRF (with noted limitations)
  • Accuracy ~73% on test datasets
  • Manual adjustment support for complex textures or patterns

We also implemented automatic merging of overlapping classes and optimized boundaries using CRF. While CRF improved segmentation in many cases, it struggled when clothing colors were similar to each other or the background. As PGN is state‑of‑the‑art but not perfect, manual adjustments were sometimes required, especially for complex textures or patterns.

Tools & Technologies

The solution was implemented in Python, leveraging the CIHP‑PGN network for segmentation. PIL was used for accurate resizing, while OpenCV handled preprocessing tasks. CRF was applied for boundary refinement, though with limitations in color similarity scenarios. The architecture emphasized speed, accuracy, and adaptability, ensuring scalability for real‑world fashion AI use cases.
